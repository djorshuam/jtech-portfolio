As duas peças, e por que as duas

Muita gente instala só a primeira e acha que o resultado ficou ruim. As peças fazem coisas diferentes e se completam.

Peça 1 — capacidade

Servidor MCP

O powerbi-modeling-mcp, oficial da Microsoft. É ele que abre a conexão e entrega 21 ferramentas para ler e escrever no modelo. Sem ele, o Claude não alcança o Power BI.

Peça 2 — julgamento

Skill

Um arquivo de texto que ensina como usar aquelas ferramentas: a ordem certa, o que confirmar antes de alterar o modelo e as ciladas do caminho. Sem ela, o Claude tem as ferramentas mas erra a mão.

Analogia

O servidor é a caixa de ferramentas. A skill é o manual do técnico. Entregar a caixa sem o manual é o que faz a IA sair criando medida no lugar errado.

1

Node.js, o único pré-requisito

Não precisa de Python, nem de SQL Server Management Studio, nem de driver nenhum. Confira no Prompt de Comando:

Prompt de Comando 
node --version

Se responder com um número de versão, siga. Se não, instale:

Prompt de Comando 
winget install --id OpenJS.NodeJS.LTS --exact --accept-package-agreements --accept-source-agreements
Depois de instalar

A janela de terminal que já estava aberta continua com o caminho antigo e não enxerga o Node novo. Feche e abra outra antes de continuar.

2

Instalar o servidor MCP

No Claude Desktop, abra Configurações → Servidores MCP locais → Editar configuração. Esse botão abre o arquivo certo — não precisa procurar pasta.

Se o arquivo estiver vazio, cole exatamente isto:

claude_desktop_config.json 
{
  "mcpServers": {
    "powerbi-modeling": {
      "command": "C:\\Program Files\\nodejs\\npx.cmd",
      "args": [
        "-y",
        "@microsoft/powerbi-modeling-mcp@latest",
        "--start",
        "--readwrite",
        "--require-confirmation"
      ]
    }
  }
}
Armadilha nº 1

Escrever só "npx" em vez do caminho completo. No Windows o Claude Desktop nem sempre resolve o comando pelo PATH, e o servidor falha com connection closed — sem dizer o motivo. Se o seu Node estiver em outro lugar, descubra com where npx e use aquele caminho.

Armadilha nº 2

Barras invertidas precisam ser duplas dentro do JSON: C:\\Program Files\\…. E se você já tiver outros servidores no arquivo, acrescente a entrada em vez de substituir o bloco. Um JSON inválido faz o Claude ignorar o arquivo inteiro, e todos os seus servidores somem de uma vez.

Depois de salvar, feche o Claude Desktop por completo — inclusive pelo ícone ao lado do relógio — e abra de novo.

No Claude Code, é um comando

Terminal 
claude mcp add powerbi-modeling --scope project -- npx -y @microsoft/powerbi-modeling-mcp@latest --start --readwrite --require-confirmation

Use --scope project para o servidor carregar só na pasta em que você trabalha. São 21 ferramentas: em escopo global elas entram no contexto de toda sessão, inclusive em projetos que nada têm a ver com Power BI.

3

Escolher o modo de operação

As três combinações de parâmetros mudam bastante o comportamento. Vale entender antes de decidir, porque a do meio é perigosa:

ParâmetrosLeitura e DAXAlterar o modelo
--startdiretobloqueado
--start --readwritediretopermitido, sem avisar
--start --readwrite --require-confirmationdiretopede sua aprovação

A terceira é a que recomendo, e é a que está no JSON acima. Consulta e DAX passam sem atrito nenhum; só alteração no modelo abre um pedido de aprovação.

Cuidado com a do meio

Com --readwrite sozinho, a IA cria e apaga medidas do seu relatório sem perguntar nada. É seu arquivo de trabalho: não vale a economia de dois cliques.

4

Montar a skill

Uma skill é uma pasta com um arquivo SKILL.md dentro. O arquivo começa com um cabeçalho YAML de dois campos obrigatórios, e o resto é instrução em texto comum. Estrutura mínima:

estrutura de pastas 
powerbi-modeling/
└── SKILL.md

O cabeçalho decide se a skill será usada

O campo description é o que o Claude lê para decidir se aquela skill serve para o pedido. Descrição vaga significa skill que nunca dispara. Escreva as palavras que você realmente usa no dia a dia:

SKILL.md — cabeçalho 
---
name: powerbi-modeling
description: Trabalhar com modelos do Power BI abertos localmente no
  Power BI Desktop. Use quando o usuario falar em "meu Power BI", "meu
  relatorio", "minhas medidas", pedir para criar ou corrigir uma medida
  DAX, auditar o modelo, ou pedir um numero que vem de um .pbix aberto.
---

O corpo: as regras que fazem diferença

Aqui vai o que a ferramenta sozinha não ensina. Estas são as regras que mudaram o resultado na prática:

SKILL.md — corpo 
# Power BI Desktop via MCP

## Fluxo obrigatorio

1. connection_operations com {"operation": "ListLocalInstances"}
2. connection_operations com {"operation": "Connect",
   "connectionString": "data source=localhost:PORTA"}
3. so entao as demais ferramentas

A porta MUDA toda vez que o Power BI Desktop abre. Nunca reaproveite
porta de conversa anterior nem chute um valor.

O ListLocalInstances devolve parentWindowTitle, o nome do relatorio
aberto. Confirme com o usuario que e o arquivo certo antes de alterar
qualquer coisa.

## Descubra a API pela propria ferramenta

Toda ferramenta aceita {"operation": "Help"}, e a resposta traz os
parametros obrigatorios, os erros comuns e exemplos prontos. Use isso
em vez de adivinhar.

## Antes de modificar o modelo

1. Diga o que vai mudar, com o DAX exato, antes de mudar
2. Valide o DAX com dax_query_operations / Validate
3. Sugira salvar o .pbix antes de alteracoes em lote
4. Em lote, use Options.UseTransaction = true
5. Nao faca alteracoes que ninguem pediu

## Armadilhas de medidas

- Esquecer TableName no Create e o erro mais comum
- Update nao muda a tabela de uma medida: para isso existe Move
- Delete tem ShouldCascadeDelete = true por padrao, e apaga as
  dependencias junto
Por que isso importa

A regra da porta sozinha já evita a maior parte dos erros. Ela muda a cada abertura do Power BI, e sem essa instrução o Claude tenta reaproveitar a porta da conversa anterior e falha com uma mensagem de rede que não explica nada.

5

Importar a skill no Claude

Pronta para usar

A skill completa deste tutorial, já empacotada no formato que o Claude aceita. Baixe e pule direto para a importação.

Baixar powerbi-modeling.zip

Prefere montar do zero? O conteúdo está na etapa 4 — crie a pasta powerbi-modeling, salve o SKILL.md dentro e compacte a pasta, não o arquivo:

o que o zip deve conter 
powerbi-modeling.zip
└── powerbi-modeling/
    └── SKILL.md

Onde clicar

A tela de habilidades fica nas configurações do Claude Desktop. O caminho é curto, mas o botão certo não é o mais óbvio:

Caminho até essa janela

No Claude Desktop, abra as configurações e procure por Habilidades (em inglês, Customize → Skills). É uma janela separada da de Servidores MCP locais, que você usou na etapa 2 — são configurações diferentes, e é comum confundir as duas.

Se a importação recusar o arquivo

Quase sempre é o zip montado errado: o SKILL.md ficou solto na raiz em vez de dentro da pasta. Abra o zip e confirme que existe a pasta powerbi-modeling dentro dele.

Antes de testar

Confirme que Configurações → Capabilities → Code execution and file creation está ligado. Sem isso as habilidades não carregam, e o Claude simplesmente ignora a skill sem avisar.

6

Testar na ordem certa

Abra um .pbix no Power BI Desktop e vá do mais inofensivo ao mais arriscado. Se o primeiro falhar, não adianta tentar o terceiro.

  1. Leitura: “liste as medidas do meu Power BI” — deve responder sem pedir nada.
  2. Consulta: “quantas linhas tem a tabela Vendas?” — DAX, também sem prompt.
  3. Escrita: “crie uma medida _teste com a expressão 1” — aqui deve aparecer o pedido de aprovação.
Antes do teste 3

Salve o .pbix. É a primeira vez que algo vai escrever no seu modelo, e você quer poder voltar atrás.

Se não achar o Power BI

O programa precisa estar aberto com um arquivo carregado. Só a tela inicial não basta: o motor de dados sobe junto com o arquivo.

Armadilhas reais, e o que cada uma significa

Todas estas apareceram numa instalação de verdade. As mensagens são pouco explicativas, então vale reconhecê-las pelo sintoma:

SintomaCausaCorreção
connection closed Comando npx sem caminho completo Usar C:\Program Files\nodejs\npx.cmd
Tempo esgotado ao conectar Primeira execução baixando o pacote e estourando o limite do cliente Rodar npx -y @microsoft/powerbi-modeling-mcp@latest uma vez no terminal para preencher o cache
“Nenhuma instância encontrada” Power BI fechado, ou aberto sem arquivo Abrir um .pbix
Erro de certificado Proxy da empresa interceptando o tráfego Definir NODE_OPTIONS=--use-system-ca
Todos os servidores sumiram JSON inválido — vírgula a mais ou a menos Validar o arquivo e corrigir a pontuação
Segurança — leia antes de copiar solução da internet

A “solução” mais divulgada para erro de certificado é NODE_TLS_REJECT_UNAUTHORIZED=0. Ela funciona porque desliga a verificação de certificado em todo programa Node da máquina, não só neste. É abrir a porta para qualquer um interceptar seu tráfego.

O certo é NODE_OPTIONS=--use-system-ca: o Node passa a confiar nos certificados já instalados no Windows — onde o certificado da sua empresa costuma estar — mantendo a verificação ligada.

PowerShell 
[Environment]::SetEnvironmentVariable('NODE_OPTIONS','--use-system-ca','User')

O que ele não faz

O servidor mexe no modelo: tabelas, colunas, medidas, relações, hierarquias e segurança de linha. Ele não edita páginas, visuais nem layout do relatório — essa parte continua no braço. E as alterações ficam no arquivo aberto: você ainda precisa salvar.

Sem custo

Seguir este guia não custa nada, e continua assim. O servidor é da Microsoft, a skill está escrita aqui inteira e o zip está pronto para baixar. Faça o passo a passo e você tem o Claude conversando com o seu Power BI sem pagar nada — nem para a J Tech, nem para ninguém.

O que a J Tech cobra é o trabalho que o tutorial não faz por você: sair de uma máquina e chegar numa equipe inteira, com o modelo de vocês e com quem responde se algo quebrar.

Implantação em time

Instalação e configuração em todas as máquinas, definição do modo de operação e treinamento da equipe. Sai do “funciona no meu computador”.

Skill sob medida

Uma versão que conhece o seu modelo: convenções de nomes, dicionário de dados e os padrões DAX da casa. A skill genérica deste tutorial é a demonstração; a sua é o produto.

Treinamento

Curso ou workshop de Power BI com IA para a equipe de dados, com material de apoio e exercícios sobre os relatórios que vocês já usam.

Auditoria de modelo

Revisão do modelo semântico — medidas duplicadas, relações frágeis, DAX caro, RLS mal definido. Você recebe o laudo e o plano de correção.
